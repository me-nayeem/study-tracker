মোট প্রশ্ন: ১১টি (MCQ ১০ + CQ ১) স্কোর: ০/১০
সৃজনশীল প্রশ্ন
মনে করি, A = [[4, -1], [2, 3]], B = [[1, 5], [-2, 0]] এবং C = [[0, 0], [0, 0]]।
ক) দুটি ম্যাট্রিক্স সমান হওয়ার শর্ত লেখ।জ্ঞানমূলক, মান-১
Bekkha: দুটি ম্যাট্রিক্স সমান হতে হলে তাদের ক্রম একই হতে হবে এবং একই অবস্থানের প্রতিটি অনুরূপ উপাদান পরস্পর সমান হতে হবে।
খ) A + C = A হবে কেন ব্যাখ্যা কর।অনুধাবনমূলক, মান-২
Bekkha: C = [[0,0],[0,0]] একটি শূন্য বা নাল ম্যাট্রিক্স, যা additive identity হিসেবে কাজ করে। A এর প্রতিটি উপাদানের সাথে C এর অনুরূপ উপাদান (0) যোগ করলে A এর উপাদানই অপরিবর্তিত থাকে, তাই A + C = A।
গ) A + B এবং A − B নির্ণয় কর।প্রয়োগ, মান-৩
Bekkha: A+B = [[4+1, −1+5], [2+(−2), 3+0]] = [[5, 4], [0, 3]]
A−B = [[4−1, −1−5], [2−(−2), 3−0]] = [[3, −6], [4, 3]]
ঘ) দেখাও যে, (A+B) − B = A।উচ্চতর দক্ষতা, মান-৪
Bekkha: (A+B) − B = [[5,4],[0,3]] − [[1,5],[-2,0]] = [[5−1, 4−5], [0−(−2), 3−0]] = [[4, −1], [2, 3]] = A। (প্রমাণিত)
